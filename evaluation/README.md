# 上游评估脚本

本目录保留 EduAgent 的评估程序，供研究固定题目、检索与工作流测量方法。它们不是 CodeMentor 的真实用户效果实验，也不属于当前 CI 的性能验收。

`run_all.py` 和各 `benchmark_*.py` 的生成物写入 `results/`，该目录已从发布候选排除。上游曾保存的分数与耗时只属于当时的输入/环境，不能引用为当前准确率、幻觉率、用户学习提升或线上延迟。没有为开源准备重新运行或改写这些结果。

当前可信的功能回归入口是项目根目录的 `python -m pytest tests`；无付费模型的轻量运行方式见主 README。保留这些脚本不表示真实模型、完整 RAG 或性能实验已通过本轮验证。
