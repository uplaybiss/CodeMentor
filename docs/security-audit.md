# 开源安全检查报告

审计日期：2026-10-15。范围为当时的 CodeMentor 工作树、索引、完整可达 Git 历史、reflog/悬空对象及依赖许可。本报告是带日期的本地安全检查记录，不表示仓库、Release 或 CI 的实时状态。

## 检查方法与结论

| 项目 | 实际检查与处理 |
| --- | --- |
| Git 历史完整性 | 原为单提交浅克隆；从已有公开上游只读补全后，完整可达历史共 3 个提交。没有改写或删除上游历史。 |
| 密钥/令牌/密码 | 对工作文件和 Git blob/commit 对象扫描已知 Provider Token、私钥、带口令 URL、JWT 及凭据赋值，并复核候选。未发现已知模式的真实硬编码凭据。 |
| 误报复核 | 3 行 Provider 配置对象属性引用及同一 Git blob 中对应 3 行被识别为候选；它们从 Settings 读取变量，不包含密钥字面量。 |
| 本地 `.env` | 两项非空 API Key 配置经检查为占位符，未记录取值。`.env` 不在发布树；新的 `.env.example` 两项密钥均为空，默认 Demo/关闭检索。 |
| 数据库与检查点 | 识别 26 个本地数据库文件，只读检查其表和记录数量，不公开学生、对话、成绩或运行状态内容。业务库、检查点、WAL/SHM、向量数据和上传目录均排除。 |
| 日志与路径隐私 | 初始暂存的验收日志中有本机用户路径；已移出索引并忽略。它们不在已提交上游历史中；本地对象库可能仍保留旧索引 blob，不应打包 `.git`。 |
| 生成物和测试账号 | 日志、验收证据、历史响应 JSON、旧基准结果、内部交接资料不随当前候选分发。测试源码中的固定虚构 ID 和 FakeEmbedder 保留，不将其当作真实用户数据。 |
| Git 索引整理 | 分两次将 105 项与 1 项缓存/生成文件移出索引，合计 106 项；每次均验证本地文件内容哈希不变，未删除本地文件。 |
| 分词缓存 | 本地缓存保留，候选排除；安装/CI 由 tiktoken 从官方源下载并校验词表，无模型 API 调用。 |
| 第三方许可 | 保留 EduAgent MIT 版权，增加 CodeMentor 修改归属；145 个实际安装分发与 152 个完整可选解析分发的元数据合并为 168 个包/版本组合，均有许可声明，详见依赖清单。 |

扫描覆盖 OpenAI、Google、GitHub、Slack、AWS、JWT/私钥及通用凭据赋值等已知模式，同时检查邮箱、手机号样式与用户目录。数字型二进制数据的手机号样式不视为已确认个人电话；对应数据库整体按私有数据排除。上游公开提交作者信息作为继承历史元数据保留，没有代换为虚构作者。

## 发布树的保护

`.gitignore` 覆盖 `.env`、Streamlit Secret、常见私钥/证书、Python 环境、缓存、数据库及旁路文件、上传、日志、验收材料和旧生成结果。`.env.example` 与必要的 Streamlit 主题配置保留。

忽略规则不自动移除已暂存文件，因此本轮实际执行了“仅从索引移除”，并验证磁盘副本保留。也没有通过删除测试或改写业务实现来绕过检查。

源码分发应按经过审查的 Git 文件清单逐文件构建，不递归打包工作目录；不含 `.git`、`.env`、`.venv`、数据库、日志、上传、模型权重或个人验收截图。原始审计输出保留在本地私有工作目录，公开报告仅记录结论与数量。

## 剩余风险和发布约束

1. **许可选择**：PyMuPDF 的 PDF 功能涉及 AGPL/商业许可；certifi、orjson、tqdm 和 wheel 附带组件也有各自条款。MIT 项目声明不豁免这些义务，完整 PDF/RAG 分发或公开服务前应确认适用方案。见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
2. **身份与数据边界**：当前 ID/档案名不提供认证；部分读取接口和文档共享语料不是完整多租户系统。线上 Demo 需访问控制、虚构数据和单实例运行，不能直接接入真实学生隐私或开放付费 Provider。
3. **依赖与平台**：安装和许可元数据检查不等同于已完成漏洞渗透测试；完整可选模型栈仅做 Windows 解析，Linux 条件依赖和真实 Provider/模型权重仍需目标环境复核。
4. **审计时效**：已知模式扫描不是绝对无泄露保证。若后续加入新密钥、数据或生成物，需对最终 commit 再扫一次。若发现历史真实密钥，应先撤销/轮换，再在备份下确定历史清理方案，不得直接推送。

本次审计没有发现需要立即轮换的历史真实密钥，没有改写上游历史或删除本地运行数据。远程测试结果应另行查看 [GitHub Actions](https://github.com/uplaybiss/CodeMentor/actions/workflows/ci.yml)，不能从本地扫描结论推定 CI 已通过。
